# Bakery Shop

A modern Bakery & Cake Shop web application built with React, TypeScript, Vite, and Tailwind CSS. Features interactive 3D/video hero sequence, custom cake builder, menu catalog, shopping cart, and order checkout experience.

## Tech Stack
- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React / SVG
- **State Management**: Zustand

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
